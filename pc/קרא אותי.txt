ביטיצ'אט - התוכנה למחשב
========================

1. לחלץ קודם: לחיצה ימנית על BTChat-PC.zip ← "חלץ הכל".
   לא להפעיל את BTChat.exe ישר מתוך ה-ZIP.

2. להעביר את התיקייה למקום קבוע (למשל המסמכים), ולהפעיל משם את BTChat.exe.
   בהפעלה הראשונה התוכנה שואלת אם להפעיל אותה עם כל הדלקה של המחשב.

3. בפעם הראשונה נפתח חלון Chrome נפרד על גוגל צ'אט: מתחברים בו לחשבון גוגל.
   אחר כך החלון מוסתר לגמרי, והתוכנה עובדת ברקע (האייקון ליד השעון).
   לחשבון נוסף: בחלון של התוכנה ← "הוספת חשבון".

4. הנגן צריך להיות משויך למחשב בבלוטות', והאפליקציה BTChat.apk מותקנת בו.
   התוכנה מוצאת את הנגן לבד.

צריך Chrome או Edge מותקנים במחשב.

אם האנטי-וירוס של Windows חוסם את התוכנה:
התוכנה חדשה ואין לה חתימה דיגיטלית בתשלום, ולכן Windows עלול לחשוד בה. זו התרעת שווא.
כדי לאשר: אבטחת Windows ← הגנה מפני וירוסים ואיומים ← היסטוריית הגנה ← בוחרים את הפריט ← פעולות ← "אפשר במכשיר".

הקוד פתוח: https://github.com/Xnet2/btchat
